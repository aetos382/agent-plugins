# agent-plugins

A [Claude Code plugin marketplace](https://code.claude.com/docs/en/plugin-marketplaces) by aetos382.

## Plugins

| Plugin | Description |
|---|---|
| [dev-container-feature-development](plugins/dev-container-feature-development) | Skills for authoring, testing, and releasing [Dev Container Features](https://containers.dev/implementors/features/). |

See each plugin's README for its components and requirements.

## Installation

Add this marketplace, then install the plugins you need:

```
/plugin marketplace add aetos382/agent-plugins
/plugin install <plugin>@aetos382
```

The plugins target the latest version of Claude Code.
